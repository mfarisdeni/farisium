## Deployment

Vercel (Hosting & CDN)

Deployment dilakukan melalui integrasi GitHub.

Setiap push commit ke branch utama (main) otomatis mendeploy lewat Vercel (auto-deploy).

Tidak menggunakan proses manager (PM2) atau upload manual.
